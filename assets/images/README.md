# 躲避球图片资源

请将你的躲避球PNG图片放在这个目录中：

## 需要的图片文件：

1. **red_ball.png** - 红色躲避球图片
2. **blue_ball.png** - 蓝色躲避球图片

## 图片要求：

- 格式：PNG（推荐透明背景）
- 尺寸：建议 64x64 像素或更高（正方形）
- 颜色：
  - red_ball.png：红色主题的球
  - blue_ball.png：蓝色主题的球

## 说明：

将你的图片文件重命名为上述确切的文件名，然后放置在此目录中。游戏会根据队伍自动选择相应的球图片。

游戏中球的显示大小会根据游戏设置自动调整（默认半径为8像素，即直径16像素）。
