# 创建躲避球图片指南

如果你需要创建自己的躲避球图片，可以按照以下步骤：

## 方法1: 使用图片编辑软件
1. 创建64x64像素的正方形画布
2. 绘制一个圆形的球
3. 添加适当的阴影和高光效果
4. 使用透明背景
5. 保存为PNG格式

## 方法2: 使用在线图标生成器
1. 搜索"球 图标"或"ball icon"
2. 选择合适的球形图标
3. 下载PNG格式
4. 重命名为red_ball.png和blue_ball.png

## 方法3: 使用现有图片
1. 找到合适的球类图片
2. 使用图片编辑软件将背景设为透明
3. 调整颜色（红色/蓝色）
4. 调整尺寸为合适大小
5. 保存为PNG格式

## 颜色建议：
- **红球**: #FF5252 (亮红色) 或类似红色
- **蓝球**: #42A5F5 (亮蓝色) 或类似蓝色

确保图片文件名为：
- `red_ball.png`
- `blue_ball.png`
