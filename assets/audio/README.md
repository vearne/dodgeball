# 音频文件说明

请将以下音频文件放置在此文件夹中：

## 必需文件

1. **background_music.mp3** - 背景音乐
   - 建议：轻快、循环的游戏背景音乐
   - 时长：2-3分钟（可循环播放）
   - 格式：MP3

2. **hit_sound.mp3** - 击中音效
   - 建议：清脆的击中声
   - 时长：0.5-1秒
   - 格式：MP3

3. **throw_sound.mp3** - 投掷音效
   - 建议：投掷球的声音
   - 时长：0.5-1秒
   - 格式：MP3

4. **victory_sound.mp3** - 胜利音效
   - 建议：欢快的胜利音乐
   - 时长：2-3秒
   - 格式：MP3

## 获取音频文件的方法

### 方法1：使用免费音频资源
- [Freesound](https://freesound.org/) - 免费音效库
- [OpenGameArt](https://opengameart.org/) - 免费游戏音频
- [Zapsplat](https://www.zapsplat.com/) - 免费音效（需要注册）

### 方法2：使用AI生成
- 使用AI工具生成简单的音效
- 确保版权合规

### 方法3：自己制作
- 使用Audacity等音频编辑软件
- 录制或合成音效

## 注意事项

1. **版权问题**：确保使用的音频文件有合法的使用权限
2. **文件大小**：建议每个文件不超过1MB，以保持应用轻量化
3. **音质**：建议使用128kbps或以上的音质
4. **格式**：统一使用MP3格式，确保兼容性

## 测试

放置音频文件后，可以在音频设置界面中测试音效是否正常工作。
