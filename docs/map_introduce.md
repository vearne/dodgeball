# 地图文件格式说明

本文档详细说明地图配置 JSON 文件中各个字段的含义和使用方法。

## 文件位置

- **内置地图**：`assets/config/missions/mission_1.json` 到 `mission_30.json`
- **自定义地图**：应用文档目录下的 `missions/` 文件夹

## 完整示例

```json
{
  "id": "1",
  "name": "关卡 1",
  "description": "新手教程关卡",
  "enemyCount": 5,
  "obstacles": [
    {
      "type": "rock",
      "x": 870.0,
      "y": 60.0,
      "width": 60.0,
      "height": 60.0
    },
    {
      "type": "brickWall",
      "x": 150.0,
      "y": 360.0,
      "width": 240.0,
      "height": 60.0
    }
  ],
  "allowedPowerUps": ["health", "speedBoost"],
  "powerUpSpawnInterval": 30.0,
  "playerInitialPositions": [
    {
      "x": 300.0,
      "y": 360.0,
      "playerId": 0
    },
    {
      "x": 400.0,
      "y": 360.0,
      "playerId": 1
    }
  ],
  "maxPowerUps": 5
}
```

## 字段说明

### 1. id

- **类型**：字符串
- **必需**：是
- **描述**：关卡唯一标识符
- **示例**：
  - 内置关卡：`"1"`, `"2"`, ..., `"30"`
  - 自定义关卡：`"custom_mission1"`, `"custom_boss_level"` 等
- **说明**：
  - 内置关卡使用数字字符串
  - 自定义关卡建议以 `"custom_"` 开头
  - 系统会按 ID 排序显示关卡

---

### 2. name

- **类型**：字符串
- **必需**：是
- **描述**：关卡显示名称
- **示例**：`"关卡 1"`, `"新手教程"`, `"BOSS战"`
- **说明**：在关卡选择界面显示的名称

---

### 3. description

- **类型**：字符串
- **必需**：是
- **描述**：关卡描述文本
- **示例**：
  - `""`（空字符串，无描述）
  - `"消灭所有敌人"`
  - `"小心！敌人数量众多"`
- **说明**：可以为空，用于向玩家说明关卡目标或提示

---

### 4. enemyCount

- **类型**：整数
- **必需**：是
- **描述**：敌人数量
- **示例**：`3`, `5`, `10`
- **说明**：
  - 敌人会在蓝队区域（右侧）随机生成
  - 敌人固定为 1 条生命
  - 敌人智能等级由游戏参数 `aiIntelligenceLevel` 控制

---

### 5. obstacles

- **类型**：对象数组
- **必需**：否（默认为空数组）
- **描述**：地图障碍物列表
- **数组元素结构**：

#### type（障碍物类型）

- **类型**：字符串
- **必需**：是
- **可选值**：
  - `"rock"` - 岩石（被球击中后反弹，不消失）
  - `"brickWall"` - 砖墙（被球击中后逐渐损坏，耐久度 3）
  - `"woodWall"` - 木墙（已废弃，兼容旧地图）

#### x, y

- **类型**：数字
- **必需**：是
- **描述**：障碍物左上角坐标（像素）
- **坐标系**：从左上角 (0, 0) 开始

#### width, height

- **类型**：数字
- **必需**：是
- **描述**：障碍物的宽度和高度（像素）

**示例**：

```json
"obstacles": [
  {
    "type": "rock",
    "x": 870.0,
    "y": 60.0,
    "width": 60.0,
    "height": 60.0
  },
  {
    "type": "brickWall",
    "x": 150.0,
    "y": 360.0,
    "width": 240.0,
    "height": 60.0
  }
]
```

---

### 6. allowedPowerUps

- **类型**：字符串数组
- **必需**：否（默认为空数组）
- **描述**：允许出现的道具类型
- **可选值**：
  - `"health"` - 血瓶：拾取后增加 1 条生命
  - `"speedBoost"` - 速度靴子：移动速度增加 20%，持续 10 秒
  - `"attackSpeed"` - 攻速球：投掷冷却时间缩短，持续 30 秒
- **说明**：
  - 如果为空数组 `[]`，则不会生成任何道具
  - 敌人被击杀时有 30% 概率掉落道具
  - 定时器也会在随机位置投放道具
- **示例**：

```json
// 只允许血瓶
"allowedPowerUps": ["health"]

// 允许所有道具
"allowedPowerUps": ["health", "speedBoost", "attackSpeed"]

// 不允许任何道具
"allowedPowerUps": []
```

---

### 7. powerUpSpawnInterval

- **类型**：数字
- **必需**：否（默认 30.0）
- **描述**：道具定时投放间隔（秒）
- **示例**：`15.0`, `30.0`, `60.0`
- **说明**：
  - 仅在 `allowedPowerUps` 不为空时生效
  - 定时器会在地图随机空白位置投放道具
  - 如果设置了 `maxPowerUps`，达到上限后不再投放

---

### 8. playerInitialPositions

- **类型**：对象数组（可选）
- **必需**：否
- **描述**：玩家初始位置配置
- **数组元素结构**：

#### x, y

- **类型**：数字
- **必需**：是
- **描述**：玩家初始坐标（像素）
- **说明**：
  - 坐标系从左上角 (0, 0) 开始
  - 系统会自动检测位置有效性
  - 如果与障碍物冲突，会寻找最近的有效位置

#### playerId

- **类型**：整数
- **必需**：是
- **可选值**：
  - `0` - 玩家 1
  - `1` - 玩家 2（仅在双人模式下有效）
- **说明**：
  - 如果不配置，使用默认位置
  - 玩家 1 默认位置：红队区域左侧 1/3 处，垂直居中
  - 玩家 2 默认位置：红队区域左侧 2/3 处，垂直居中

**示例**：

```json
// 只配置玩家1位置
"playerInitialPositions": [
  {
    "x": 300.0,
    "y": 360.0,
    "playerId": 0
  }
]

// 配置双人位置
"playerInitialPositions": [
  {
    "x": 300.0,
    "y": 360.0,
    "playerId": 0
  },
  {
    "x": 400.0,
    "y": 360.0,
    "playerId": 1
  }
]

// 不配置（使用默认位置）
"playerInitialPositions": null
```

---

### 9. maxPowerUps

- **类型**：整数或 null
- **必需**：否（默认 null）
- **描述**：道具投放的最大数量限制
- **示例**：`3`, `5`, `10`
- **说明**：
  - 如果为 `null` 或不设置，则无限制
  - 当前道具数量达到上限后不再投放新道具
  - 道具被拾取后，计数器递减，可以继续投放
  - 计数器包括：
    - 敌人被击杀掉落的道具
    - 定时器投放的道具
- **示例**：

```json
// 最多同时存在 5 个道具
"maxPowerUps": 5

// 无限制（默认）
"maxPowerUps": null
```

## 地图坐标系

- **原点**：左上角 (0, 0)
- **X 轴**：向右为正方向
- **Y 轴**：向下为正方向
- **单位**：像素

## 区域划分

地图分为两个主要区域：

### 红队区域（玩家）

- **位置**：地图左侧
- **玩家限制**：玩家只能在红队区域内移动
- **敌人生成**：不在红队区域生成

### 蓝队区域（敌人）

- **位置**：地图右侧
- **敌人生成**：敌人在蓝队区域随机生成
- **玩家限制**：玩家不能进入蓝队区域

## 最佳实践

1. **障碍物设计**
   - 确保障碍物不阻挡玩家的所有移动路径
   - 留出足够的空间供玩家躲避
   - 使用岩石作为固定掩体，砖墙作为可破坏障碍物

2. **玩家初始位置**
   - 优先选择安全的位置，避免生成在敌人直接攻击范围内
   - 考虑双人游戏时，两个玩家之间保持适当距离
   - 确保初始位置附近有掩体

3. **道具配置**
   - 新手关卡减少道具种类和数量
   - 高难度关卡可以增加道具类型
   - 合理设置 `maxPowerUps` 避免道具过多
   - `powerUpSpawnInterval` 建议设置为 20-60 秒

4. **敌人数量**
   - 根据障碍物密度调整敌人数量
   - 开阔区域可以放置更多敌人
   - 密集障碍物区域减少敌人数量

## 常见问题

### Q: 为什么道具没有生成？

A: 检查以下几点：
1. `allowedPowerUps` 是否为空数组
2. `maxPowerUps` 是否已经达到上限
3. 地图空间是否过于拥挤，找不到有效投放位置

### Q: 玩家生成在障碍物上了怎么办？

A: 系统会自动检测并寻找最近的有效位置。如果找不到，会使用红队区域内的默认位置。

### Q: 如何创建自定义关卡？

A: 在应用文档目录下的 `missions/` 文件夹中创建 JSON 文件，文件名格式为 `mission_<ID>.json`。建议使用 `"custom_"` 前缀作为 ID。
