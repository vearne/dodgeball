# 输入设置功能说明

## 概述

本应用支持灵活的键盘和手柄输入配置，允许玩家自定义按键绑定。

## 功能特性

### 1. 键盘配置
- **玩家1和玩家2独立配置**：每个玩家可以设置自己的键位
- **支持的按键**：
  - 字母键（A-Z）
  - 数字键（0-9）
  - 方向键（↑↓←→）
  - 特殊键（空格、回车、Shift、Ctrl、Alt等）
  - 功能键（F1-F12）

### 2. 可配置的操作
- **移动控制**：上、下、左、右
- **动作控制**：投掷

### 3. 手柄支持
- 自动检测手柄连接
- 摇杆控制移动
- 按钮控制投掷
- 无需额外配置

## 使用方法

### 访问设置界面
1. 在游戏首页，点击右上角的设置图标（⚙️）
2. 进入输入设置界面

### 配置键位
1. 选择要配置的玩家（玩家1或玩家2）
2. 点击要修改的操作按钮（如"上"、"下"等）
3. 按下键盘上想要绑定的按键
4. 按键会立即更新显示
5. 点击右上角的保存图标（💾）保存配置

### 重置为默认设置
- 点击"重置为默认设置"按钮恢复默认键位
- 默认配置：
  - **玩家1**：WASD移动 + 空格投掷
  - **玩家2**：IJKL移动 + 数字0投掷

## 技术实现

### 文件结构
```
lib/
├── screens/
│   └── input_settings_screen.dart  # 输入设置界面
├── game/
│   ├── keyboard_config.dart        # 键盘配置类
│   ├── gamepad_config.dart         # 手柄配置类
│   └── input_controller.dart       # 输入控制器
```

### 配置保存
- 使用 `SharedPreferences` 持久化存储
- 配置在应用重启后自动加载
- 每个玩家的配置独立存储

### 配置加载流程
1. 应用启动时，`InputController` 尝试加载保存的配置
2. 如果没有保存的配置，使用默认配置
3. 配置通过 `KeyboardConfig.load(playerId)` 方法加载

### 按键检测
- 使用 Flutter 的 `KeyboardListener` 监听键盘事件
- 实时捕获按键并更新配置
- 支持热键重绑定

## 注意事项

1. **按键冲突**：避免为不同操作绑定相同的按键
2. **手柄兼容性**：大多数标准手柄（Xbox、PlayStation等）都支持
3. **配置存储**：配置保存在设备本地，不会同步到云端
4. **多玩家模式**：确保两个玩家的按键不冲突

## 故障排除

### 按键不响应
1. 确认已保存配置
2. 尝试重置为默认设置
3. 检查是否有其他应用占用按键

### 手柄不工作
1. 确认手柄已正确连接
2. 尝试断开重新连接手柄
3. 检查系统是否识别手柄设备

### 配置丢失
1. 检查应用是否有存储权限
2. 尝试手动保存配置
3. 重新配置并保存
